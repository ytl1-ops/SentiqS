Captures 1080 × 1920 produites par scripts/apercu-visuels.js (dossier play-store/) sur le cache publié.

Les photos des sources ne figurent pas sur ces captures : elles appartiennent
à leurs auteurs, et une fiche commerciale ne peut pas les montrer. Le script
active donc « économiser les données » pour ce format.

Pour les récupérer : onglet Actions > « Aperçu des visuels » de la dernière
PR qui touche la page, ou la branche `apercus/pr-<n>`, dossier `play-store/`.
Relire chaque capture avant de la téléverser : le contenu est celui du cache
du jour (un titre mal classé y apparaît tel quel).
