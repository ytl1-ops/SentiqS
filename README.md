# SentiqS
SentiqS est un système intelligent de pilotage de la sûreté destiné à surveiller, analyser, anticiper et coordonner les risques dans tout type d'environnement sensible : - entreprises - sites industriels - plateformes logistiques - infrastructures critiques - zones urbaines - institutions
